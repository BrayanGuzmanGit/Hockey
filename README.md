# Hookey

Juego de hockey de mesa para jugar contra la computadora o con otra persona en el mismo teclado.

## Jugar en Windows

[Descargar Hookey para Windows de 64 bits](https://github.com/BrayanGuzmanGit/Hockey/raw/refs/heads/main/Hookey-Windows.zip)

Extrae el ZIP y abre `hookey.exe`. En el menú puedes elegir una partida individual o multijugador local.

## Abrir el proyecto en Godot

Importa `project.godot` con Godot 4.7.2 y pulsa **F6** en la escena que quieras probar o **F5** para iniciar el juego desde el menú.
